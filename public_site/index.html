CityFragility

How do hypothetical road closures change shortest drivable distances to mapped healthcare in central Karachi?

Static explorer · precomputed scenarios

When a road closes, the nearest mapped healthcare facility can suddenly be much farther away

Getting to care in a city depends on the road network, not just straight-line distance: one-way streets, detours and blocked links change which mapped facility is truly closest. CityFragility measures this for one carefully bounded slice of central Karachi — it “closed” 100 real OpenStreetMap ways (whole road centre-line features, each of which can span several physical street segments) in a computer model of the driving network and recalculated, from 100 sample locations, how far the nearest mapped healthcare facility became by road. That is 10,000 before-and-after measurements, published with their uncertainties.

This page is a static exploration of those saved, precomputed scenarios — the numbers were measured once on the real network and stored; nothing here runs a new simulation. There is no live simulation here. For the interactive single-closure simulator, run the local application described in the project README.

Affected = sampled origins whose nearest-facility route got longer (or vanished) after closing that whole way. +m = extra drivable metres. Disc. = sampled origins left with no drivable path to any mapped facility. These are modelled access changes for a sample — not real flood risk, not verified emergency care, not citywide impact.

The same 10,000 measurements were re-ranked on two splits of the sample. Each row shows how many of the top five roads appear in both halves of the split. These are descriptive counts from the stored analysis — not a statistical significance test.

Explore the full interactive project locally

The complete application — live single-closure simulation with route comparison on the real graph, the full explorer, and the validated findings panel — runs locally in one command (see the project README.md):

cd CityFragility
env/conda/bin/python -m uvicorn webapp.server:app --host 127.0.0.1 --port 8000
# open http://127.0.0.1:8000

The local app loads the real 45,304-node routing graph on first live simulation. This static page never does.
